# Поддерживаемая версия fserg

Этот форк сохраняет два исправления автономной работы Kimi в BB:

1. **Автономные этапы и очередь промптов.** ACP передаёт события самостоятельно запущенных этапов и завершает ожидающий промпт по его собственному идентификатору. События предыдущего этапа не завершают следующий промпт преждевременно.
2. **Ложные паузы целей.** При неизменных настройках выполнения BB передаёт сообщения через штатный `agent.steer`, без `session/cancel`. При загрузке сохраняется статус ранее активной цели. Stop, явно приостановленные и заблокированные цели сохраняют прежнее поведение.

Основа: плагин `0.2.16`, Kimi `2.4.1`, SDK `0.6.90`. Точные коммиты и SHA-256 SDK указаны в [base.json](patches/kimi-code/base.json). SDK новее закреплённого нельзя подменять без повторной проверки: генератор откажется изменять неизвестный бандл.

## Установка и проверка

Нужны Git, Node **24.15 или новее в ветке 24 LTS**, npm и BB. В этом форке runtime разворачивается рядом с плагином, поэтому установка — из постоянного локального checkout. Для другого host нужно отдельно подготовить такой же checkout; автоматическая доставка runtime на удалённые host пока не реализована.

```powershell
npm ci --ignore-scripts
node scripts/build-native-steer.mjs
npm run runtime:prepare
npm test
npm run typecheck
npm run runtime:test
npm run build
bb plugin install . --yes
```

`runtime:prepare` проверяет базовый коммит, применяет патчи и устанавливает зависимости Kimi из frozen lockfile. Повторный запуск не накладывает патчи повторно. `.runtime`, `node_modules`, сгенерированный SDK и `dist` не входят в Git. Подготовленный checkout нельзя удалять или перемещать, пока он установлен в BB.

Основной процесс ACP запускается прямо из `scripts/launch-kimi.mjs`. Для команд обслуживания (`--version` и других) launcher использует обычный установленный Kimi. Вход в аккаунт остаётся через `kimi login`.

## Границы изменения

- Согласование `agentCapabilities._meta["bb.nativeSteer"]` включает передачу через `session/prompt` с `_meta["bb.steer"]`. Отказ принять сообщение возвращается ошибкой, без скрытого cancel и без ложного `input.accepted`.
- При изменении настроек выполнения применяется штатная процедура BB с остановкой и согласованием новых настроек. Это включает сужение разрешений и смену модели.
- Флаг `KIMI_CODE_EXPERIMENTAL_GOAL_PRESERVE_ACTIVE_ON_RESUME=1` действует только в ACP-процессе форка. Он сохраняет **persisted active**, не возобновляет сохранённые `paused`/`blocked`, не создаёт цель и не запускает работу сам по себе при загрузке.
- Уже приостановленную цель нужно возобновить явно. Штатное закрытие агента также может сохранить паузу. `/goal resume` не добавляется в набор ACP-команд этим патчем.
- Установка новой версии не переписывает код уже работающего процесса. Новый runtime применяется при следующем запуске/восстановлении сессии.

## Как отслеживать апстрим

```powershell
npm run upstream:check
git fetch upstream
git log HEAD..upstream/main --oneline
```

Проверка читает актуальные коммиты плагина и Kimi, последнюю версию SDK и состояние [issue #8](https://github.com/dpolishuk/bb-kimi-code/issues/8). Она ничего не обновляет. Закрытие issue или новая версия не означают, что патчи уже можно удалить.

| Патч | Условие удаления |
| --- | --- |
| `001-autonomous-turns.patch` | На чистом новом Kimi проходят тесты автономного этапа, очереди промпта и Stop без ACP driver из `e2e-turn.test.ts`. |
| `002-native-steering-and-goal-restore.patch` + генератор SDK | На чистом новом стеке сообщение о прогрессе не отправляет cancel, следующий этап запускается автоматически, Stop останавливает, replay сохраняет active и не возобновляет paused/blocked. |
| `003-windows-test-paths.patch` | В апстриме исправлены сравнения путей в Windows; полный ACP-набор проходит без нормализующего патча. |

При обновлении создавайте отдельную ветку, меняйте pins и проверяйте каждый фикс на **непатченом** кандидате, перенося только регрессионные тесты. Затем удаляйте лишь доказанно ненужные патчи, пересоздавайте `combined.patch`, запускайте `npm test`, `npm run runtime:test`, typecheck и build. `combined.patch` — совокупный diff для проверки идемпотентности; отдельные патчи — для применения и отслеживания владельца исправления.

На 2026-11-02 проверено: плагин upstream не изменился относительно pins; Kimi и SDK имеют новые версии; issue #8 открыт. Исправленность новых версий пока не установлена.

## Проверки этой версии

- 72 теста плагина прошли, включая native steer, отказ, Stop, смену разрешений и запуск ACP. 11 тестов с живыми запросами к модели намеренно выключены стандартным `BB_KIMI_LIVE` gate.
- 158 ACP-тестов и 114 тестов управления целями прошли в закреплённом Kimi с патчами.
- TypeScript-проверка плагина и ACP прошла; `bb plugin build` прошёл.
- В end-to-end тестах используется настоящий движок Kimi и ACP transport, подменяется только ответ сетевой модели.

Для отката сохраните текущую установленную копию до установки форка. `bb plugin install <путь-к-резервной-копии> --yes` возвращает предыдущий плагин. Не восстанавливайте старый публичный релиз вместо резервной копии, если требуется сохранить первое локальное исправление.
